= Installation

== Comme dépendance d'un autre shard

Ajoutez à votre `shard.yml` :

[source,yaml]
----
dependencies:
  pdf-tools:
    github: aloli-crystal/pdf-tools
    version: "~> 0.1"
----

Puis :

[source,shell]
----
shards install
----

== En local pour développer

[source,shell]
----
git clone git@github.com:aloli-crystal/pdf-tools.git
cd pdf-tools
shards install
crystal spec       # lancer les tests
----
